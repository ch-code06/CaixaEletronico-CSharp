#  Caixa Eletrônico em C#

Projeto de um sistema de caixa eletrônico desenvolvido em C# como parte dos meus estudos em Análise e Desenvolvimento de Sistemas (ADS).

##  Sobre o projeto

O objetivo é simular o funcionamento básico de um caixa eletrônico, permitindo que o usuário realize operações bancárias por meio de um menu interativo no terminal.

##  Funcionalidades

- Autenticação por CPF e senha.
- Limite de 3 tentativas para digitar a senha.
- Consulta de saldo.
- Realização de depósitos.
- Realização de saques.
- Verificação de saldo disponível.
- Encerramento do sistema.

##  Tecnologias utilizadas

- C#
- .NET
- Visual Studio Code

##  Conceitos praticados

- Variáveis e tipos de dados.
- Estruturas condicionais (`if`, `else` e `switch`).
- Estruturas de repetição (`while` e `for`).
- Operadores matemáticos.
- Manipulação de entradas do usuário.
- Lógica de programação.

##  Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o comando:

```bash
dotnet run
```
